# Dashboard and personal list shortcuts

Normal sign-in now lands at `/dashboard`; sign-in from a shared list still returns to that list. `/lists` continues to manage owned lists. The dashboard has pinned shortcuts, five owned-list previews, five saved-list previews, and links to creation/management, saved lists, and discovery. Its sections are ordinary reusable Razor components so future featured content can be added independently. No ads, affiliate integration, follows, invitations, or inferred relationships are included in this milestone.

Signed-in viewers can choose **Save this list** when viewing a public list or a valid private share link. Owned lists can be pinned from their detail page or the dashboard. `/saved` pages through personal shortcuts and provides pin/unpin and remove actions. Removing a shortcut never deletes the underlying list. Pins use save order in this version; manual reordering is deferred. The dashboard shows at most twenty pinned shortcuts, with the complete collection available under Saved lists.

`SavedList` stores the account, list, optional source share-link ID, and pin preference. It contains no raw bearer token, purchase data, or copied list title. The API validates the presented link before saving. A signed-in account can subsequently reopen the list without finding the original URL, but the access resolver rechecks the referenced link's activity, list scope, expiry, and revocation on every private view or purchase operation. A saved public list does not grant access if it later becomes private unless there is still a valid saved share grant. Guest credentials alone never grant saved access.

Unavailable shortcuts display only **List unavailable** and can be removed. Summaries omit purchase totals, fulfillment, buyer information, and share secrets. All dashboard and saved-list API/page responses use no-store. Records are account-scoped, duplicate active shortcuts are prevented by a filtered unique index, removal archives only the personal reference, and the additive migration preserves existing lists and links.

Tests cover account isolation, private reopening through saved grants, revocation, generic unavailable summaries, duplicate saves, pin/unpin, remove/re-save, owner shortcut behavior, default versus shared-list sign-in routing, UI actions, and dashboard browser navigation/pinning at desktop/mobile widths. Existing coverage thresholds remain enforced by CI.
